# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Overview

This is a personal dotfiles repository managed with chezmoi. It holds configuration for
Neovim, the Ghostty terminal, the Herdr multiplexer, the yabai / skhd / sketchybar window
management stack, zsh, and the AI coding agents (Claude Code, Codex, opencode).

## Common Commands

### Neovim Plugin Management
```bash
# Open Neovim and let LazyVim auto-install plugins
nvim

# Update all plugins (within Neovim)
:Lazy update

# Clean unused plugins (within Neovim)
:Lazy clean
```

### Tests
```bash
# Run every test under tests/
bash tests/run-tests.sh

# Run one test
bash tests/test-keybindings.sh
```

### Repository Management
```bash
# Commit configuration changes
git add .
git commit -m "chore: update configuration"
git push
```

## Architecture and Structure

### Directory Organization
- `private_dot_config/` - everything distributed to `~/.config`
  - `nvim/` - Neovim configuration based on LazyVim
    - `lua/config/` - Core LazyVim configuration (keymaps, options, autocmds)
    - `lua/plugins/` - Plugin configurations split by functionality
  - `ghostty/`, `herdr/`, `zsh/` - terminal, multiplexer, shell
  - `yabai/`, `skhd/`, `borders/`, `sketchybar/` - macOS window management and status bar
  - `claude/`, `codex/`, `opencode/` - AI coding agent configuration
  - `docs/` - tool inventory, keybindings, worktree notes and the Paseo history
    workaround, distributed to `~/.config/docs/`
- `private_dot_agents/` - shared skills and agent definitions distributed to `~/.agents`
- `.chezmoitemplates/` - templates shared across targets (Brewfile, agent skills, MCP lists)
- `.chezmoiscripts/` - install scripts run by `chezmoi apply` when a manifest changes
- `Library/LaunchAgents/` - macOS launch agents
- `tests/` - shell tests for the templates and docs, not distributed

### Key Development Integrations

**AI Development (Claude Code)**
- Neovim drives the CLI agents through sidekick.nvim
  (`private_dot_config/nvim/lua/plugins/sidekick.lua`)
- Primary keybindings: `<leader>a` prefix for AI operations, `<c-.>` for quick toggle

**Task Management**
- Overseer.nvim comes from the LazyVim extra `editor.overseer`, enabled in
  `~/.config/nvim/lazyvim.json`. That file is generated by `:LazyExtras` and is not under
  chezmoi, so the extras list is not reproducible from this repository
- No predefined tasks - relies on project-specific configuration

**Language Support**
- TypeScript, Astro, C# (dotnet), JSON, Kotlin, Rust, TOML via LazyVim extras
- Biome formatter for web development (the `lang.typescript.biome` extra)
- Stylua for Lua formatting (2 spaces, 120 column width)

**Japanese Input**
- AquaSKK provides system-wide Japanese input. It is installed by hand rather than by
  `chezmoi apply`, and its dictionaries live in `~/.config/skk` outside chezmoi.
  See the 手動インストール section of `private_dot_config/docs/tools.md`

### Terminal Environment
- Ghostty is the terminal emulator (`private_dot_config/ghostty/`)
- Herdr is the multiplexer used for agent panes (`private_dot_config/herdr/`)

## Development Notes

- Installation runs through `chezmoi apply`. The five scripts in `.chezmoiscripts/` install
  Homebrew packages, mise runtimes, the AI CLIs, npm globals and cargo globals whenever the
  matching manifest changes
- `bash tests/run-tests.sh` runs the repository's shell tests
- Tool inventory and install routes are documented in `private_dot_config/docs/tools.md`
- Dependencies: Homebrew, Neovim, Git, and mise (which supplies node / python / java / pnpm / deno)

## Chezmoi (dotfiles 管理)

`~/.config` 配下のファイルは chezmoi で管理されている。以下のルールを厳守すること。

### 編集ルール
- `~/.config` 内のファイルを修正する場合は、**必ず chezmoi ソース (`~/.local/share/chezmoi/`) 側を編集**すること。直接 `~/.config` のファイルを編集してはならない
- chezmoi ソースを編集した後、`chezmoi apply` で反映する
- chezmoi ソースのパス規則: `~/.config/foo/bar` → `~/.local/share/chezmoi/private_dot_config/foo/bar` (ドットファイルは `dot_` プレフィックス、private ディレクトリは `private_` プレフィックス)

### 編集前の確認
- コード編集を始める前に `chezmoi diff` を実行し、未反映の変更（編集途中のもの）がないか確認する
- 差分がある場合は、ユーザーに状況を伝え、どうするか確認を取ってから作業を進める
- **絶対に `chezmoi apply` を勝手に実行しないこと**。ユーザーの明示的な許可なしに apply してはならない

### キーバインドを変更したとき

キーバインドを追加・変更・削除したら、`private_dot_config/docs/keybindings.md`
も同じコミットで更新する。このファイルが skhd / Ghostty / Herdr / Neovim / zsh /
lazygit の全キーバインドと、層をまたいで奪われるキーの一覧を持っている。

`bash tests/test-keybindings.sh` がドキュメントと設定ファイルの整合を検証する。
